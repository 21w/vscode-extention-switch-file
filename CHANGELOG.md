# Change Log

All notable changes to the "open-test-file" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.4.0] - 2026-02-18

### Added
- Java file support (`.java` files)
- Toggle between Java implementation files (`*.java`) and test files (`*Test.java`)

### Changed
- Updated keybinding to `Command+Shift+T` for better compatibility

## [1.3.0]

### Added
- `.tsx` file support
- TypeScript React file and test file toggling
- `.test.tsx` test file format support

## [1.2.0]

### Added
- Bidirectional toggle feature: open implementation files from test files
- Toggle between implementation and test files with `Command+Shift+T`
- Glob pattern search for more reliable file finding

## [1.1.0]

### Added
- Workspace-wide test file search
- Improved handling for files in different directory hierarchies
- Enhanced error messages

## [1.0.0]

### Added
- Initial release with `Command+Shift+T` keybinding support

## [Unreleased]

- Future enhancements and features
